📖 Comment lier le bot

Suis ces étapes sur ton Android ou ton iPhone pour connecter le bot ƘƖƦƛ ƁƠƬ ƬЄƇӇ 🌹 à ton WhatsApp.

📲 Sur Android

  • Ouvre WhatsApp puis touche les trois points en haut à droite.
  • Va dans « Appareils liés ».
  • Touche « Lier un appareil », puis « Lier avec un numéro de téléphone ».
  • Saisis le code à 8 caractères affiché sur cette page.

🍏 Sur iPhone

  • Choisis « Appareils liés ».
  • Touche « Lier un appareil » puis « Lier avec un numéro de téléphone ».
  • Entre le code à 8 caractères et confirme.
